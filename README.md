# Materiais Complementares – Mapeamento Sistemático da Literatura sobre o Ensino de IHC

Este repositório disponibiliza os arquivos complementares utilizados no processo de realização do Mapeamento Sistemático da Literatura (MSL) sobre o ensino de Interação Humano-Computador (IHC).

## Arquivos disponíveis

| Arquivo | Descrição |
|---|---|
| [1. Busca inicial](1busca_inicial.xls) | Resultados obtidos na busca inicial nas bases de dados. |
| [2. Artigos duplicados](2Artigos_duplicados.xlsx) | Registros identificados como duplicados. |
| [3. Artigos para leitura de resumo](3Artigos_leituraabs.xls) | Artigos selecionados para análise de título e resumo. |
| [4. Artigos excluídos](4Artigos_excluidos20.xls) | Artigos excluídos durante o processo de seleção. |
| [5. Artigos finais](5Artigos_final.xlsx) | Conjunto final de artigos selecionados para o mapeamento. |

Os arquivos estão disponíveis para consulta e download público.
